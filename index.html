О приложении

MusicDesk — личная мастерская преподавателя музыки.

Версия прототипа 3.1. В этой версии нет серверной синхронизации, аккаунтов и доступа учеников.

Не храни здесь чувствительные персональные данные. Экспортированные резервные копии могут содержать личные заметки — сохраняй их в надёжном месте.

☁ Облачное подключение (тест)

Сначала подключаем аккаунт преподавателя. Не вводи сюда секретный ключ или service_role. Данные будут отправляться в облако только после входа и выбора действия.

Не подключено. Локальное автосохранение продолжает работать.

При первом подключении, если в облаке уже есть данные, приложение спросит, какую копию оставить. Перед проверкой сделай резервную копию JSON.

Планы со временем сортируются по времени. План без времени можно перемещать стрелками по всему списку.

＋ Прочая работа (например, звукозапись)

Отметь план галочкой после выполнения — сумма попадёт в недельный доход.

Начни вводить имя — затем нажми на нужный результат.

Пробный урок можно провести без карточки ученика. Обычные уроки не требуют отдельной отметки оплаты. Для пробного урока появится отдельная кнопка подтверждения оплаты.

＋ Подробности плана (время, тема, место, подготовка)
＋ Подзадачи (чек-лист внутри плана)

Подзадачи скрыты внутри подробностей плана; выполнение отмечается отдельно.

Планы сохраняются локально в этом браузере. Не забудь делать резервную копию.
